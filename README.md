# Game Character Save System

## Description
This Java program creates game characters and saves their information to JSON and XML files. It then reads and displays the contents of both files.

Each character includes a name, class, level, health, attack power, and gold.

## How to Run
1. Open the project in IntelliJ IDEA.
2. Run `Main.java`.
3. The program creates `characters.json` and `characters.xml`.

## Concepts Used
- Java classes and objects
- ArrayLists
- File reading and writing
- JSON and XML formatting
- Exception handling
